# テスト入力データ

各プロンプト用のテスト入力データの例です。APIリクエストの`input_data`フィールドに使用してください。

## 1. 長文要約 (gpt-5-thinking)

### 基本テスト
```json
{
  "text": "人工知能（AI）は、現代社会において急速に発展している技術分野です。機械学習、深層学習、自然言語処理などの技術が進歩し、様々な産業でAIの活用が進んでいます。医療分野では、AIを活用した画像診断や創薬研究が行われており、診断精度の向上や新薬開発の加速が期待されています。金融分野では、不正検知やリスク管理、アルゴリズム取引などにAIが活用されています。製造業では、品質管理や予知保全、ロボット制御などにAIが導入されています。また、自動運転技術や音声アシスタント、翻訳サービスなど、私たちの日常生活にもAI技術が浸透しています。しかし、AIの普及に伴い、プライバシーの保護、雇用への影響、アルゴリズムの公平性など、様々な課題も浮上しています。これらの課題に対処するため、倫理的なAI開発や規制の整備が求められています。"

```

### 長文テスト（10,000文字以上）
長文テキストを用意して、`text`フィールドに入力してください。例：技術文書、論文、記事など。

## 使用方法

1. プロンプトIDを取得（`/api/prompts`エンドポイントから）
2. 上記のJSONデータを`input_data`として使用
3. APIリクエスト例：
```json
{
  "prompt_id": 1,
  "input_data": {
    "text": "..."
  }
}
```

## 注意事項

- オプショナルフィールドは省略可能です
- 空文字列や`null`を指定すると、その行は自動的に削除されます
- 長文テストでは、10,000文字以上のテキストを使用してください
