# Prompt Provision Tool - ユーザーガイド

## 🚀 クイックスタート

### 管理者向け（5分で始める）

#### ステップ1: ログイン
1. ブラウザで `http://your-domain/static/admin/login.html` を開く
2. 管理者アカウントでログイン

#### ステップ2: 子アカウント作成
1. 「アカウント管理」をクリック
2. 「新規アカウント作成」ボタン
3. 以下を入力:
   ```
   ユーザー名: user1
   メール: user1@example.com
   パスワード: user123
   アカウント種別: CHILD（子アカウント）
   ```
4. 「作成」ボタン

#### ステップ3: プロンプト作成
1. 「プロンプト管理」をクリック
2. 「新規プロンプト作成」ボタン
3. 以下を入力:

**名前**: 文章要約プロンプト

**説明**: 長文を簡潔に要約します

**モデル**: gpt-4

**プロンプト内容**:
```
あなたは優秀な要約アシスタントです。
以下の文章を読んで、重要なポイントを3-5点にまとめて要約してください。

【文章】
{text}

【要約のポイント】
- 主要な情報を漏らさない
- 簡潔で分かりやすく
- 箇条書きで出力
```

**Input Schema**:
```json
{
  "type": "object",
  "properties": {
    "text": {
      "type": "string",
      "title": "要約する文章",
      "description": "要約したい長文を入力してください"
    }
  },
  "required": ["text"]
}
```

4. 「作成」ボタン

#### ステップ4: プロンプトを割り当て
1. 「アカウント管理」に戻る
2. `user1` の行の「プロンプト割り当て」ボタン
3. 「文章要約プロンプト」を選択
4. 「割り当て」ボタン

✅ **完了！** これでuser1がプロンプトを使えるようになりました。

### ユーザー向け（使い方）

#### ステップ1: ログイン
1. ブラウザで `http://your-domain/static/user/login.html` を開く
2. ユーザー名とパスワードを入力
3. ログインボタン

#### ステップ2: プロンプトを選択
- ダッシュボードに使えるプロンプト一覧が表示される
- 使いたいプロンプトの「実行」ボタンをクリック

#### ステップ3: 入力して実行
1. 入力フォームが表示される
2. 必要な情報を入力（例：要約したい文章）
3. 「実行」ボタンをクリック
4. 数秒待つ
5. 結果が表示される！

#### ステップ4: 履歴確認
- 「実行履歴」メニューから過去の実行結果を確認できる

## 📝 プロンプトテンプレートの書き方

### 基本ルール

1. **プレースホルダー**: `{variable_name}` の形式で変数を指定
2. **Input Schema**: JSON Schemaで入力フィールドを定義
3. **わかりやすい指示**: AIに何をしてほしいか明確に書く

### 例1: シンプルな要約

**プロンプト**:
```
以下の文章を3行で要約してください。

{text}
```

**Input Schema**:
```json
{
  "type": "object",
  "properties": {
    "text": {"type": "string", "title": "文章"}
  },
  "required": ["text"]
}
```

### 例2: 複数の入力

**プロンプト**:
```
{language}で{task}を実装してください。

要件:
- コメントを含める
- エラーハンドリング
- ベストプラクティスに従う
```

**Input Schema**:
```json
{
  "type": "object",
  "properties": {
    "language": {"type": "string", "title": "言語"},
    "task": {"type": "string", "title": "タスク"}
  },
  "required": ["language", "task"]
}
```

### 例3: 詳細な説明付き

**Input Schema**:
```json
{
  "type": "object",
  "properties": {
    "text": {
      "type": "string",
      "title": "要約する文章",
      "description": "要約したい長文を入力してください（最大5000文字）"
    },
    "length": {
      "type": "string",
      "title": "要約の長さ",
      "description": "short（短い）/ medium（普通）/ long（詳細）"
    }
  },
  "required": ["text"]
}
```

## 🔧 トラブルシューティング

### Q: プロンプトが表示されない
**A**: 管理者にプロンプトの割り当てを依頼してください。

### Q: 実行ボタンを押してもエラーになる
**A**: 以下を確認:
1. すべての必須項目（赤い*マーク）を入力したか
2. インターネット接続は正常か
3. しばらく待ってから再度試す

### Q: 結果が表示されるまで時間がかかる
**A**: AI APIの処理時間です。通常3-10秒かかります。長い文章や複雑な処理はより時間がかかる場合があります。

### Q: 履歴を削除したい
**A**: 現在、履歴の削除機能はありません。管理者に依頼してください。

## 💡 ベストプラクティス

### プロンプト作成のコツ（管理者向け）

1. **明確な指示**
   - ❌ 悪い例: "これを処理して"
   - ✅ 良い例: "以下の文章を3-5点の箇条書きで要約してください"

2. **具体的な出力形式**
   ```
   【出力フォーマット】
   - タイトル: ...
   - 要約: ...
   - キーワード: ...
   ```

3. **役割を明確に**
   ```
   あなたは優秀な{役割}です。
   例: 技術ライター、データアナリスト、翻訳者
   ```

4. **制約を明示**
   ```
   - 300文字以内で要約
   - 専門用語は避ける
   - 敬語を使用
   ```

### 効果的な使い方（ユーザー向け）

1. **具体的な入力**
   - 曖昧な入力よりも具体的な内容を
   - 必要な文脈を含める

2. **適切な長さ**
   - 短すぎず、長すぎない入力
   - 推奨: 100-5000文字

3. **期待する結果を意識**
   - プロンプトの説明をよく読む
   - 求められている入力形式に従う

## 📊 統計・ログの見方

### 実行履歴の項目

| 項目 | 説明 |
|------|------|
| **実行日時** | プロンプトを実行した日時 |
| **プロンプト名** | 使用したプロンプト |
| **入力データ** | 入力した内容（JSON形式） |
| **出力データ** | AIの応答 |
| **使用モデル** | gpt-4, gpt-4-turbo-preview など |
| **実行時間** | 処理にかかった時間（ミリ秒） |
| **トークン数** | 消費したトークン数（課金に関係） |
| **ステータス** | success（成功）/ error（エラー） |

### トークン数について

- **トークン** = AIが処理する単位（単語や文字の塊）
- **日本語**: 約2-3文字 = 1トークン
- **英語**: 約4文字 = 1トークン
- **コスト**: トークン数に応じて課金される

**例**:
- 入力500文字 + 出力300文字 = 約400トークン
- GPT-4の場合: 約$0.012

## 🔐 セキュリティとプライバシー

### 保護されているもの
✅ プロンプトの内容（暗号化保存）
✅ パスワード（ハッシュ化）
✅ 通信内容（JWT認証）

### 記録されているもの
📝 実行ログ（入力・出力・実行時間）

### 注意事項
⚠️ 入力データはログに保存されます

## 🎓 FAQ

### Q: プロンプトの内容は見られますか？
A: いいえ。プロンプトは暗号化されており、ユーザーには内容が送信されません。入力フォームと結果のみが表示されます。

### Q: 自分でプロンプトを作成できますか？
A: 子アカウント（CHILD）は作成できません。管理者（PARENT）のみが作成できます。

### Q: 実行回数に制限はありますか？
A: 現在は制限なし。将来的にレート制限が設定される可能性があります。

### Q: 過去の実行結果を再利用できますか？
A: 実行履歴から過去の入力・出力を確認できます。コピー＆ペーストで再利用可能です。

### Q: モバイルで使えますか？
A: はい。レスポンシブデザインなのでスマートフォンやタブレットでも使用できます。

### Q: オフラインで使えますか？
A: いいえ。AI APIへのアクセスが必要なため、インターネット接続が必須です。

### Q: 複数のプロンプトを同時に実行できますか？
A: 複数のブラウザタブで同時に実行可能です。
